## Summary

- **The vendor, not the broker, applies for the license, but a BAREIS member must ask in writing first.** The member (broker/agent) emails `idx@norcalmls.com` with member name, vendor name and a description of the services. Only then does BAREIS send the vendor an application. Fee: $50 non-refundable application, plus data-license fees quoted during the application. Processing 3-6 weeks (FAQ) or 4-8 weeks (older 2020 form). Credentials are issued only after the fee is paid and the license agreement is signed. This is the plan-critical path: budget about 1-2 months and make the client broker file the request first. (CONFIRMED*)
- **The broker must be opted in to IDX with BAREIS** before IDX links or a vendor feed work. (CONFIRMED*)
- **The vendor application asks "API or RETS".** So BAREIS offers both on paper. The platform is Rapattoni (the MLS software vendor); Rapattoni publishes a RESO Web API with OAuth2 password and authorization-code grants, with the client secret issued by MLS staff. Endpoint URLs and resource names are not public in anything I could read. Design the adapter against the RESO Web API (OData) and treat the exact base URL as a post-approval input. (RAPATTONI vendor link CONFIRMED* from BAREIS app listing; RESO API detail REPORTED/CONFIRMED* from rapattoni.com/dev excerpt.)
- **There is a published, official list of licensed IDX vendors** on bareis.com. Names seen in excerpt: Agent Fire, BoomTown ROI, CINC, iHomefinder, Lone Wolf, Market Leader, MoxiWorks, Placester, Real Geeks, RealScout, Rover IDX, SimplyRETS, Showcase IDX, Ylopo (list is longer and I could not read it in full). A custom Omnikom build is **not** on that list and would need its own license. SimplyRETS being listed is a lead: a vendor that already holds a BAREIS license could in principle relay data (this would need BAREIS agreement; do not assume).
- **Display rules (from Rule 14.4, 2025/2026 revision, CONFIRMED*):** refresh at least every 12 hours; show source and last-update date; show listing brokerage firm name and listing agent on every listing; consumer personal/non-commercial-use notice; no Confidential Information fields; do not modify data; honor "do not pass to the Internet" and seller address-withhold flags; do not filter or hide listings by buyer-broker compensation or listing broker name. Exact disclaimer wording and logo rule NOT found.
- **Pending and Sold are tiered and the sources conflict.** Rules define "IDX Internet Data" = Active + Contingent with Pass-to-Internet = yes; "IDX Enhanced Internet Data" = adds Pending and 180 days Closed, only if the broker has signed a BAREIS IDX license agreement. A BAREIS help page about Rapattoni IDX links says Active, Contingent, Pending, Closed publish-flagged listings are eligible. Design: ship Active + Contingent first; make Pending/Sold a feature flag that is only on after BAREIS confirms in writing.
- **One IDX feed does NOT automatically include other MLSs.** iHomefinder states each MLS provides a separate IDX feed and cross-MLS sharing is for professional logins, not public IDX sites. However, the NorCal MLS Alliance has announced a **Combined IDX feed** (date about mid-2026, unconfirmed) for six MLSs including BAREIS, with its own process: at least one active Alliance subscriber on the site, an Alliance Data Request Form, sign-off from each MLS that adds data, and each MLS's own license fees (REPORTED, from SFAR guidance via a third party). MetroList is a member of the Alliance but was NOT in Bay East's list of six MLSs in the combined IDX announcement as excerpted. So: plan one BAREIS feed first; treat combined feed as phase 2 and a separate approval.
- **Territory:** Fairfield, Suisun City, Vacaville (Northern Solano County AOR area), Vallejo and Benicia (Solano Association of REALTORS area) and Napa and American Canyon (Napa County) are all in BAREIS counties. BAREIS serves all of Solano and Napa counties. So all seven cities are BAREIS territory; none needs MetroList or bridgeMLS for the base listing set. (CONFIRMED* / REPORTED, details below.)

## Process as we understand it

1. Client broker (Participant) is opted in to IDX with BAREIS. If not, opt in first (needed before IDX links or vendor feed work). [Facts 7, 10]
2. A BAREIS member (broker or agent) sends a written request to `idx@norcalmls.com` naming the member, the vendor and the services. If the requester is an agent, the Participant (broker) is copied to approve. Omnikom does not send this; the client broker does. [Fact 2]
3. BAREIS sends the vendor (Omnikom, or whichever licensed vendor is used) the data-license application. Pay the $50 non-refundable fee. Be ready to supply: privacy and security policy URL, California Secretary of State registration, E&O or media/network liability insurance, existing MLS contracts, example product URLs, and the choice of API (RESO Web API) or RETS. [Facts 3, 6]
4. BAREIS reviews, 3-6 weeks (FAQ) or 4-8 weeks (2020 form). BAREIS decides at its sole discretion. [Facts 4, 6]
5. If approved, sign the vendor data license agreement, pay the license fee quoted in the application, and BAREIS issues credentials. Credentials come from BAREIS and its platform (Rapattoni), with the client secret issued by MLS staff. [Facts 5, 17]
6. Build against the RESO Web API (OData, OAuth2) once the endpoint URL is supplied. Implement the 12-hour minimum refresh (practical target: every 15-60 minutes), source and update-date label, listing firm and agent on every listing, consumer-use notice, honor pass-to-internet / address-withhold flags, no Confidential Information fields, no data modification. [Facts 17, 20-23]
7. Confirm in writing with BAREIS: exact disclaimer text and logo rule, whether Pending and Closed data are allowed for this broker (Enhanced tier), and the exact field list that is allowed. Keep Pending/Sold behind a flag until then. [Facts 24-26]
8. Phase 2 only, if the client wants partner-MLS listings on the public site: request the Alliance Combined IDX feed through the Alliance Data Request Form, with approval from each MLS that adds data and each MLS's fees. Do not assume the BAREIS license covers them. [Facts 31-34]
