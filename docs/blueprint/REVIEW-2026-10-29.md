write paths did not hold, and several promises in the docs have no table or function behind them. Each item below is kept
until its fix has a test that went red and a mutant; the Status column is updated as that happens.

`crm-map` 115 passed, 67 of 67 mutants; `check-specs` 0 problems. Nothing was run on a real Supabase project.
