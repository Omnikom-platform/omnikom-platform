# DSN-001 (P1, design tells): looping or bouncy motion

Source: skills/unslop/references/signs.md:85-86 and skills/unslop/SKILL.md:170-171; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-001.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-001, bad-DSN-001-hover-scale, bad-DSN-001-transition-all, bad-DSN-001-shimmer-class, bad-DSN-001-shimmer-keyframes, bad-DSN-001-stylesheet, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
A page does not use looping or bouncy motion. A `class` token (after any variant prefix such as `md:` or `hover:`, and without a leading or
trailing `!`) equal to `animate-pulse`, `animate-ping`, `animate-bounce` or `transition-all` fails; so does `scale-*` of any value (also `-scale-*`,
`scale-x-*`, `scale-y-*`) under a `hover`, `group-hover` or `peer-hover` variant; so does any class token that contains `shimmer`
(any case); so does an `@keyframes` rule whose name contains `shimmer`, in a `<style>` block or a linked stylesheet (reported once per
stylesheet file, on the file and line of the `@keyframes`).

## Judged here
Class tokens on every element of the page, and `@keyframes` names in the page's `<style>` blocks and, in a built folder, in the local
stylesheets the page links (a snapshot's stylesheets are not in the snapshot).

## Not judged here
Animation or transition declared in CSS (`animation: ... infinite`, `transition: all`): only the tokens and names above are read. A CSS rule
named `.shimmer` that no element uses is not a finding (the class on an element is). Computed styles and media queries. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
