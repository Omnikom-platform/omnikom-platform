# DSN-003 (P1, design tells): emoji in labels and headings

Source: skills/unslop/references/signs.md:27; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-003.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-003, bad-DSN-003-selector, snapshot-bad-DSN-003, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
The text of `h1` to `h6`, `button`, `a`, `label`, `legend`, `summary`, `th` and `option` contains no character that shows as an emoji: one with the Unicode
property `Emoji_Presentation`, or any `Extended_Pictographic` character followed by U+FE0F (the emoji selector). A text-style symbol passes unless it
carries U+FE0F: the bare north-east arrow of an external link, U+25B6, U+2714, U+260E, U+26A0, U+2764, the copyright, registered and trade mark signs, digits, `#` and `*`.
The text of an element includes the text of the elements inside it; an emoji is reported once, against the nearest label element that holds it.

## Judged here
This is the head's reading of DECISIONS 37 ("emoji in labels and headings") and of `skills/unslop/references/signs.md` line 27: a character is judged by how it
shows, not by the bare Unicode property `Extended_Pictographic`, which also covers text symbols such as the arrow on an external link. Examples that fail: the
rocket U+1F680, U+2B50, U+231A (emoji presentation), and the north-east arrow, U+25B6, U+2714, U+260E, U+2122 each followed by U+FE0F. The text nodes of those elements
are judged; the finding quotes the character cluster.

## Not judged here
Emoji in other elements (a paragraph, a list item, a div), in attributes (`alt`, `aria-label`, `title`), in images, in text added by
JavaScript or by CSS `content`. Text inside `svg`, `template`, `noscript`, `script`, `style` and comments is never judged. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
