## Rule text
Every internal `a[href]` (resolved with `resolveInternal`; fragment-only, `mailto:`, `tel:`, `javascript:` out of scope) lands on a page that
exists in the folder (an `.html` file, or a non-HTML file such as a PDF or image that exists); a target that is missing is status-mismatch;
an internal link with `nofollow` in `rel` is forbidden-value; a link to a page's non-canonical form (`/about.html` when the page is
`/about/`, or `index.html`) is value-mismatch.

## Judged here
- internal means a relative link or an absolute link on a host that is one of the pages' canonical hosts. A page target must be a page of the
  folder; a file target (pdf, image, css, js, xml, txt, json, zip, media, font) must be a file in the folder.
- `nofollow` in `rel` on an internal link; a page link whose path is not the page's own form (`/about.html`, `/about/index.html`, `/about`).
- the reader's `resolveInternal` returns null for file targets, so `lib/context.mjs` carries a `resolveLink` that also resolves them.

## Not judged here
The HTTP status of the link in production (folder only). External links.
