# LNK-002 (P0, web-delivery)

Source: checklist/web-delivery.md LNK-002 (skill checklist copy, the id and a cut-short text); full text from the shipgate spec 8.0.0,
pack file `shipgate/spec/packs/web-delivery.md`, read 2026-10-30 and pasted from the slice 1 brief.
Check: `checks/lnk-002.mjs`. Fixtures: `fixtures/bad-LNK-002*`.

## Rule text
Every internal `a[href]` (resolved with `resolveInternal`; fragment-only, `mailto:`, `tel:`, `javascript:` out of scope) lands on a page that
exists in the folder (an `.html` file, or a non-HTML file such as a PDF or image that exists); a target that is missing is status-mismatch;
an internal link with `nofollow` in `rel` is forbidden-value; a link to a page's non-canonical form (`/about.html` when the page is
`/about/`, or `index.html`) is value-mismatch.

## Judged here
- internal means a relative link or an absolute link on a host that is one of the pages' canonical hosts. A page target must be a page of the
  folder; a file target (pdf, image, css, js, xml, txt, json, zip, media, font) must be a file in the folder.
- `nofollow` in `rel` on an internal link; a page link whose path is not the page's own form (`/about.html`, `/about/index.html`, `/about`).
- the reader's `resolveInternal` returns null for file targets, so `lib/context.mjs` carries a `resolveLink` that also resolves them.

## Not judged here
The HTTP status of the link in production (folder only). External links.

## Snapshot mode (slice 2): the status part
A snapshot is a sample of a live site. For an internal page link, the crawl's record of the target decides:
- the target was crawled and answered 200: fine (and the canonical-form test applies as in a folder).
- the crawl saw a 3xx at the target (its first hop was 301/302/..., or its final status is 3xx): FAIL `redirect-target`.
- any other status (404, 410, 5xx, no status): FAIL `status-mismatch`.
- the target is not in the snapshot: SKIP `not-crawled` for that link (one per target and page). Never a PASS, never a FAIL: the crawl did not look.
  A page with such a SKIP prints no PASS line for this rule.
Links to files and assets are not judged in a snapshot (the crawl fetches pages only; listed in `notCovered`). A 404 or redirect record is
evidence for this rule, not a page of the site: the page rules do not run on it.
