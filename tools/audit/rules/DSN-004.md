# DSN-004 (P1, design tells): uppercase tracked labels

Source: skills/unslop/references/signs.md:19; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-004.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-004, bad-DSN-004-inline, bad-DSN-004-style-block, bad-DSN-004-stylesheet, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
No element with text is both uppercase and tracked: `uppercase` (class, or `text-transform: uppercase`) together with a positive tracking
(`tracking-wide`, `tracking-wider`, `tracking-widest`, `tracking-[<positive>]`, or a `letter-spacing` above zero) on the same element, whether
the two come from classes, a style attribute, a `<style>` block or a linked stylesheet whose plain selector reaches the element.

## Judged here
Unprefixed Tailwind classes (a `md:` or `hover:` token is not read), style attributes, `<style>` blocks and linked stylesheets in a built
folder. An element with no text is not a label and is not judged. `letter-spacing: normal` and `0` are not positive; a length that is not a plain number
(`calc()`, `var()`) is not read. Where the styles come from: the element's `class` and `style` attributes, the page's `<style>` blocks, and, in a built folder only, the
local stylesheets the page links (`<link rel="stylesheet" href>` that resolves to a file inside the folder). A stylesheet or `<style>`
selector is matched only when it is one plain class (`.card`) or one element name (`h2`), alone or in a comma list; a selector with a
combinator, a pseudo-class, an attribute, an id or a compound part is not judged. Order used: element rules, then class rules, then
Tailwind classes, then the style attribute; a later declaration of the same property wins. Specificity, media queries and inheritance
are not computed: the engine sees declared styles, not computed ones. A stylesheet's `@import` is not followed, and rules inside `@media`,
`@supports` and `@layer` are read as if they always applied.

## Not judged here
Inheritance: an uppercase parent with a tracked child is two elements and is not judged. Computed styles. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
