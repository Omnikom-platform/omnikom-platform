# DSN-008 (P1, design tells): PRO and Beta badges

Source: skills/unslop/references/signs.md:54 and skills/unslop/SKILL.md:113; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-008.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-008, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
No `span`, `small`, `sup`, `div`, `strong`, `em`, `mark` or `b` has the whole of its trimmed text equal to `PRO` or `Beta`, in any case.
When badges are nested (`<div><span>PRO</span></div>`) only the innermost is reported.

## Judged here
The whole text of those elements.

## Not judged here
A badge in another element (a button, a link, an li), a badge with more words ("Beta feature"), a badge drawn by an image or by CSS
`content`. Text inside `svg`, `template`, `noscript`, `script`, `style` and comments is never judged. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
