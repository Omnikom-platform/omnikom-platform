# DSN-011 (P1, design tells): negative letter spacing on small text

Source: skills/unslop/references/signs.md:22 and skills/unslop/SKILL.md:121; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-011.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-011, bad-DSN-011-inline, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is WARN (the exit stays 0). A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
No element with text declares a negative letter spacing at a font size under 14 px. Spacing: `tracking-tight`, `tracking-tighter`,
`tracking-[-...]`, or a `letter-spacing` below zero. Size: as in DSN-010. The verdict is a WARN: declared styles, not computed ones.

## Judged here
Both values declared on the same element. Where the styles come from: the element's `class` and `style` attributes, the page's `<style>` blocks, and, in a built folder only, the
local stylesheets the page links (`<link rel="stylesheet" href>` that resolves to a file inside the folder). A stylesheet or `<style>`
selector is matched only when it is one plain class (`.card`) or one element name (`h2`), alone or in a comma list; a selector with a
combinator, a pseudo-class, an attribute, an id or a compound part is not judged. Order used: element rules, then class rules, then
Tailwind classes, then the style attribute; a later declaration of the same property wins. Specificity, media queries and inheritance
are not computed: the engine sees declared styles, not computed ones. A stylesheet's `@import` is not followed, and rules inside `@media`,
`@supports` and `@layer` are read as if they always applied.

## Not judged here
Inheritance, media queries, `calc()` and `var()` values, em-only sizes, classes with a variant prefix. An element with no text is not judged. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
