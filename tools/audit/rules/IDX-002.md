# IDX-002 (P0, web-delivery)

Source: checklist/web-delivery.md IDX-002 (skill checklist copy, the id and a cut-short text); full text from the shipgate spec 8.0.0,
pack file `shipgate/spec/packs/web-delivery.md`, read 2026-10-30 and pasted from the slice 1 brief.
Check: `checks/idx-002.mjs` with `lib/xml.mjs`. Fixtures: `fixtures/bad-IDX-002*`.

## Rule text
<= 50,000 URLs and 52,428,800 bytes per file; sitemap index when more than one file; valid escaped XML; absolute URLs on one origin;
unique entries.

## Judged here
- per sitemap file: URL count and byte size against `sitemap.maxUrlsPerFile` and `sitemap.maxBytesPerFile` (config; the defaults are the
  spec limits, a fixture lowers them in its `audit.config.json`), well-formed XML with every `&` escaped, every `<loc>` an absolute
  http(s) URL on the origin of the first one, no `<loc>` listed twice anywhere in the folder.
- more than one sitemap file in the folder while the root file is not a `<sitemapindex>`.
- no sitemap file at all: SKIP (nothing to judge; IDX-001 reports the missing sitemap).

## Not judged here
That every file named by a sitemap index exists is not checked (IDX-001 reads every sitemap file of the folder).
