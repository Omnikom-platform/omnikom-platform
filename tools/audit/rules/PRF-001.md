# PRF-001 (P2, performance)

Source: checklist/performance.md PRF-001 (skill checklist copy, shipgate spec 8.0.0: "Per route group: parts lcp (LCP <= lcpMs), cls (CLS <= cls),
tbt (TBT <= tbtMs) and seo ..."); defaults from the shipgate spec 8.0.0, pack file `shipgate/spec/packs/performance.md`, line 11, read
2026-10-30: `lcpMs 2500, cls 0.1, tbtMs 200, inpMs 200, scriptBytes 170000, cssBytes 60000, renderBlockingMs 300, thirdPartyBlockingMs 250,
seoScore 1.0`. The same numbers are Google's Core Web Vitals "good" thresholds (web.dev/articles/vitals, read 2026-10-30: LCP 2.5 s, INP 200 ms,
CLS 0.1).
Check: `checks/prf-001.mjs`. Fixtures: `fixtures/snapshot-bad-PRF-001*`.

## Rule text
Per route group, parts `lcp` (LCP <= lcpMs), `cls` (CLS <= cls), `tbt` (TBT <= tbtMs); the finding is `budget-exceeded` showing the metric and value.

## Judged here (snapshot mode only)
- Per judged page (status 200), from `pages/<slug>/browser-mobile.json` (real Chrome, phone, slow network, written by `cdp-measure.mjs`; the
  numbers sit under `vitals`, a flat `{ lcpMs, cls, tbtMs }` is read too). Each part is its own finding: `budget-exceeded: LCP 3100 ms > 2500 ms`.
  A value equal to the budget passes. A metric that is null is a SKIP for that metric.
- Trust: `_site.json` `pages[].speedTrust` must be exactly `"trusted"`. Anything else (`UNTRUSTED: machine busy (cpu avg N%)`, or none recorded)
  is `SKIP PRF-001 <page> speed UNTRUSTED (...); take the PageSpeed Insights number`: an untrusted lab number is not a finding.
- PSI preference: when the audited folder holds `psi/<date>.json` (the newest by name), or the run is given `--psi FILE`, in the shape
  `psi.mjs` writes (`{ generatedAt, pages: [{ url, strategy, performance, lcpMs, cls, tbtMs, ... }] }`), the entry with strategy `mobile` for the
  page's URL is judged instead of the lab file, trusted or not, and a FAIL line carries `(source: PSI <date>)`. A page with no PSI entry falls back
  to its lab file. A PSI file that is not valid JSON or has no `pages` array is a usage error (exit 2).
- A page with no `browser-mobile.json` (and no PSI entry) is `SKIP ... not measured`.
- Thresholds: config `speed.lcpMs` 2500, `speed.cls` 0.1, `speed.tbtMs` 200 (`audit.config.json` overrides the defaults, `options.config`
  overrides that; each must be a number above zero, else exit 2 naming WCF-004).

## Not judged here
The `seo` part (the Lighthouse SEO category score is not in the snapshot) and the other defaults of the block (`inpMs`, `scriptBytes`,
`cssBytes`, `renderBlockingMs`, `thirdPartyBlockingMs`). Folder mode: a built folder has no measurement, so the rule prints no line there.
The lab number is one page load on this machine; only the PSI number is Google's.
