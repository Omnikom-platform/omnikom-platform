## Rule text
Title or description length outside its `warnMin` to `warnMax` range. WARN, never FAIL.
Defaults (shipgate spec 8.0.0 `packs/web-delivery.md` line 21, the default adapter config): `titleLength { warnMin: 30, warnMax: 60,
hardMax: 70 }`, `descriptionLength { warnMin: 70, warnMax: 160, hardMax: 180 }`. Overridable by `options.config` and by an
`audit.config.json` in the audited folder; WCF-004: `warnMin < warnMax <= hardMax`, else exit 2.

## Judged here
- the first non-empty title and the first non-empty description in `<head>`: a length below `warnMin` or above `warnMax` is a WARN.
  A WARN never changes the exit code. A missing or empty title or description is MET-001 / MET-002's finding, not this one.
