# DSN-006 (P1, design tells): exclamation marks in headlines

Source: skills/unslop/references/signs.md:44 and skills/unslop/SKILL.md:105; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-006.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-006, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
The text of `h1` to `h6` contains no `!`. One finding per heading, on the line of the first `!`.

## Judged here
All six heading levels, including text in elements inside the heading.

## Not judged here
Exclamation marks in buttons, paragraphs and attributes, and the full-width form. Text inside `svg`, `template`, `noscript`, `script`, `style` and comments is never judged. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
