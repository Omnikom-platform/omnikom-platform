## Rule text
On each indexable page: the same canonical string in the canonical tag, `og:url`, the page's own hreflang `href` and JSON-LD `WebPage.url`;
every hreflang `href` equals the canonical of its target page. In a folder there is no origin: the canonical must be present, absolute
(`https://`), and its path must normalise (`normPath`) to the page's own path; og:url, hreflang and WebPage.url, when present, must equal it
exactly. A missing canonical is missing-element.

## Judged here
- canonical present (else missing-element), `https://` absolute, path equal to the page's own path after `normPath`.
- every `og:url` equals the canonical; every hreflang whose href resolves to a page of the folder equals that page's canonical (for the page's
  own hreflang: this page's canonical); a `WebPage` (or subtype) node's `url` equals the canonical.
- noindex pages are not judged (the rule is for indexable pages).

## Not judged here
The origin itself (a folder has none) and hreflang targets outside the folder.
