## Rule text
`<lastmod>` (W3C datetime with time and timezone, SE-004) is the page's content modification time, or omitted.
The built-in's signature for the opposite: five or more URLs of one sitemap all share one lastmod (all within one minute) that lies within
10 minutes of the time the sitemap file was written, so the value is the build clock and not each page's content date.

## Judged here
- the signature above, per sitemap file, using the file's modification time. A WARN, never a FAIL.
- no sitemap file in the folder: SKIP.

## Not judged here
Whether a lastmod is really the page's content date (that needs the content's own history, which a folder does not carry).
