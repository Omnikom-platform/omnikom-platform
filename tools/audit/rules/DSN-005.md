# DSN-005 (P1, design tells): hype words and AI-powered copy

Source: skills/unslop/references/signs.md:47 and skills/unslop/SKILL.md:110; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-005.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-005, bad-DSN-005-hype-word, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
The visible body text holds none of these, as whole words in any case: `AI-powered` (also `AI powered`), `powered by AI`, `supercharge`,
`seamless`, `unlock`, `magic`, `revolutionize` (also revolutionise, its -s, -d and -ing forms, and `revolutionary`), `game-changing` (also
`game changing` and `game-changer`). A match is looked for across inline elements inside one block of text (`<p>Our <b>AI</b>-powered tea</p>`
matches); it does not join text across a block boundary.

## Judged here
The word list is the one in the unslop copy at `skills/unslop/references/signs.md` line 47 and `skills/unslop/SKILL.md` line 110, as DECISIONS 37
names it. `unlock` and `magic` are kept because the source names them; both are ordinary words ("unlock the door", "a magic trick") and may need a
per-site exception later. Only the listed words are whole-word matches: supercharged, seamlessly, unlocked, unlocks and magical are not matched.
Visible body text only: the `head`, `title` and the `meta` description are not body text.

## Not judged here
Every hype word outside the list. Text in attributes (`alt`, `title`) and text added by JavaScript. Text inside `svg`, `template`, `noscript`, `script`, `style` and comments is never judged. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
