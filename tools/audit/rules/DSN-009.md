# DSN-009 (P1, design tells): unverifiable-claim patterns

Source: skills/unslop/references/signs.md:71 and skills/unslop/SKILL.md:111; planning/DECISIONS.md 37 (owner, 2026-10-31); unslop by Damir Sokolovsky, CC BY 4.0
Check: `checks/dsn-009.mjs`. Fixtures (folders under `fixtures/`): bad-DSN-009, bad-DSN-009-times, bad-DSN-009-trusted, and bad-DSN (every tell on one page).
This rule is DECISIONS 37's list of design tells made into a check; the list comes from the open skill unslop by Damir Sokolovsky
(github.com/heydamir/unslop, folder skills/unslop, CC BY 4.0). The rule text below is written for this engine in our own words.
Severity P1; the verdict of each finding is FAIL. A finding names the rule, the page, the line, the exact text or class that tripped it, and the source.

## Rule text
The visible body text does not match either pattern, in any case:
- `loved by <number>[k|m][+] <word>` and `trusted by <number>[k|m][+] <word>` (`skills/unslop/references/signs.md` line 71): "Loved by 10,000+
  teams", "trusted by 5k customers". The number may carry commas and a decimal point.
- `<number>[.n] x <comparative>`: "10x faster", "3.5 x better", with `x` or the multiplication sign U+00D7 and the comparative one of faster,
  better, more, cheaper, quicker, easier, smarter, higher.
A match is looked for across inline elements inside one block of text; it does not join text across a block boundary.

## Judged here
The two patterns. The rule finds the shape of an unverifiable claim; whether a client's number is true is a person's check (DECISIONS: no
invented numbers).

## Not judged here
Other claim wordings ("number one", "award-winning", rows of avatar dots or five stars with no source). Text in attributes and text added by JavaScript. Text inside `svg`, `template`, `noscript`, `script`, `style` and comments is never judged. A snapshot (a live site saved by the skill's snapshot script) carries each page's HTML only, so in a snapshot this rule judges what the
HTML carries (classes, style attributes, `<style>` blocks, text); the site's stylesheets are not in the snapshot and are not judged.
