## Rule text
Exactly one non-empty `head > title` (an SVG `<title>` is not counted), whose length (Unicode code points of its NFC text with whitespace
collapsed and trimmed) is <= `titleLength.hardMax`; unique within locale across indexable pages (compared after NFKC, case folding and
whitespace collapse).

## Judged here
- one `<title>` in `<head>` (none: missing-element; two or more: duplicate-element at the second), non-empty, at most `titleLength.hardMax`
  code points (default 70, see README for the config), unique per `<html lang>` among indexable pages (a noindex page is not compared).
- A `<title>` inside an `<svg>` is never read: the reader removes `<svg>` blocks.

## Not judged here
Nothing of this rule is left out.
