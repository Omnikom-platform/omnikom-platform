# A11-007 (P1, accessibility)

Source: checklist/accessibility.md A11-007 (skill checklist copy, the id and a cut-short text); full text from the shipgate spec 8.0.0,
pack file `shipgate/spec/packs/accessibility.md`, read 2026-10-30 and pasted from the slice 1 brief.
Check: `checks/a11-007.mjs`. Fixtures: `fixtures/bad-A11-007*`.

## Rule text
Every `<img>`, `input[type=image]` and `area[href]` has an `alt` attribute; on `<img>`, `alt=""` (or `role=presentation|none`) marks decorative
and passes; `input[type=image]` and `area[href]` need a non-empty `alt`, `aria-label` or `aria-labelledby`; any other `alt`, trimmed, is not
empty, does not match `^[^\s/]+\.(avif|bmp|gif|jpe?g|png|svg|webp)$` (case-insensitive), is not equal to the `src` or its last path segment,
and, case-folded, is not one of the generic words `image, picture, photo, graphic, icon, logo, img` (the spec's `genericAltWords` list for
en). The browser parts (role=img names, axe rules) are SKIP.

## Judged here
All of the html channel above. The generic word list is the spec's `genericAltWords` for en; no other language list is applied.

## Not judged here
The browser channel: role=img names, button-name, link-name and the axe rules. They are listed in the check's `notCovered`, not as SKIP
lines, so that a clean site prints only PASS lines (slice 2 adds the browser channel).
