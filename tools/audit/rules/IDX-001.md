## Rule text
Sitemap URL set equals the set of indexable pages in canonical form; each discrepancy class is its own finding: extra (a URL with no page),
missing (a page not in the sitemap), non-canonical (a URL that is not the page's canonical), noindex (a page with `noindex` listed).

## Judged here
- the URLs of every sitemap file in the folder against the pages. A page's canonical form is its canonical link, or, when it has none
  (URL-009 reports that), the home page's origin plus the page path.
- no sitemap file at all is one FAIL (missing-element), not a SKIP: every indexable page is then unlisted.

## Not judged here
Nothing of this rule is left out.

## Snapshot mode (slice 2)
The sitemap files are `site/sitemap-N.xml` (or `.xml.gz`); the crawled pages are a sample unless `_site.json` says `complete: true`. On a
sample, "extra" (a listed URL with no crawled page) and "missing" (a crawled page the sitemap does not list; the saved sitemap may be cut off)
are one SKIP each, `incomplete-crawl`, naming the count and the first URLs. Judged on a sample too: non-canonical, noindex, and a listed URL
whose crawl record is not 200 (`status-mismatch`). With `complete: true` all classes are FAIL as in a folder.
