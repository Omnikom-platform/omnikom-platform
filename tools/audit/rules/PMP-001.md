# PMP-001 (P0, the prompt map covers every row)

Source: planning/DECISIONS.md 35 (the prompt map; owner, 2026-10-31)
Check: `checks/pmp-001.mjs`. Fixtures: `fixtures/good-coverage`, `fixtures/bad-PMP-001-*`.

This rule is not a line of the shipgate checklist: it is the department's own rule, the publish half of slice 5 (`tools/audit/briefs/slice-5-prompt-map.md`). A prompt is a
whole situation a buyer types into an AI engine (scenario, comparison, constraint). The skill's research stage maps the prompts (`research/prompt-map.json`), its plan
stage answers every row with a page or a written reason and writes `plan/prompt-coverage.json`; this rule refuses a build that leaves a row unanswered.

## Rule text
The coverage file is `{ map: "<sha256 of prompt-map.json>", rows: [ { id, coveredBy: "<page path>" | null, kind, reason } ] }`. It is given with the audit
(`audit(dir, { promptCoverage: FILE })`, `run.mjs --prompt-coverage FILE`, `live.mjs --prompt-coverage FILE`), never searched for.
- A row with `coveredBy: null` needs a non-empty `reason` (also an `earn-mention` row, whose reason names the offsite item). With neither: one FAIL naming the row id.
- A row whose `coveredBy` path is not a built page (`site.pageList`, the path normalised like every page path) is one FAIL naming the row id and the path.
- Every other row is one PASS line (subject: the row id).

## Judged here
- Each row of the file once. The row's page is matched by path only: the rule does not read the page, so it does not know the page answers the prompt (the plan decided that).
- A reason is judged only for being present: whitespace alone is empty.

## Not judged here
- With no file: a run prints one `SKIP PMP-001 / no --prompt-coverage ...` line (the site-wide subject `/`; no PASS, no FAIL) and judges nothing. A check that did not run is never silent.
- That `map` is the hash of the current `prompt-map.json` (the audit does not see the map; the skill's gate and `approve.mjs` own that).
- That a `coveredBy` page is indexable or carries the prompt: IDX-001, MET-* and the plan's own gate judge pages.
- A file that is not JSON, or has the wrong shape (no `rows[]`, a row with no string `id`, a `coveredBy` that is neither a path string nor null, a non-string `reason`, a repeated `id`) is a usage error (exit 2), not a finding.
